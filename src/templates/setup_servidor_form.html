2. Senha no Secret Manager. Crie o secret (pule se ele já existe, como o atlas-iw-oracle-ds-iw-password) e dê leitura à SA:

export PROJECT={{ gcp.projeto }}
export SECRET={{ gcp.secret }}
export SA={{ gcp.sa }}

gcloud secrets describe $SECRET --project=$PROJECT --format='value(name)' \
  || gcloud secrets create $SECRET --project=$PROJECT --replication-policy=automatic

# A senha vem do teclado: nao fica no historico do shell
read -rs SENHA && printf '%s' "$SENHA" \
  | gcloud secrets versions add $SECRET --project=$PROJECT --data-file=- ; unset SENHA

gcloud secrets add-iam-policy-binding $SECRET --project=$PROJECT \
  --member=serviceAccount:$SA --role=roles/secretmanager.secretAccessor --format=none

3. Cadastro. No perfil GCP (Cloud Run): o usuário e a fonte Secret Manager com o nome do secret. Não precisa de redeploy: a senha é lida a cada conexão.
