Renders a Lucide icon at the Opalus stroke weight (1.75); use it anywhere an icon is needed instead of inline SVG.

```jsx
<Icon name="activity" size={20} />
<Icon name="shield-check" size={16} color="var(--teal-500)" />
```

Load `https://unpkg.com/lucide@0.544.0/dist/umd/lucide.js` on the page first. Sizes in use: 16 (dense tables), 20 (buttons, nav), 24 (headers), 32 (feature marks).
