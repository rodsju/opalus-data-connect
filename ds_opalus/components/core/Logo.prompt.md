Renders the official Opalus lockups from `assets/` — always use this instead of typesetting or redrawing the mark.

```jsx
<Logo height={28} base="../../assets" />
<Logo lockup="vertical" tone="white" height={96} base="../../assets" />
```

Set `base` to the correct relative path from the page. Keep 1h clear space around it (`--logo-clearspace`).
