# Template — Apresentação Opalus

Copyable 16:9 deck in the Opalus system. Five layouts: capa (navy + node-mesh), divisória de seção, métricas (4 KPI tiles), gráfico de barras, encerramento.

**In a consuming project:** copy this folder, then edit the `base` line in `ds-base.js` to point at the bound `_ds/<folder>` tree relative to the page. Asset paths inside `Deck.dc.html` (`../../assets/...`) need the same adjustment.

Other layouts (agenda, comparação, citação, unidades) are available as standalone cards in `slides/` of the design system.
