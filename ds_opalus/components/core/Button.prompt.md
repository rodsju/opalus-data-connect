The standard Opalus action control — navy `primary` for the single main action per view, `secondary` for everything beside it.

```jsx
<Button icon="plus">Nova admissão</Button>
<Button variant="secondary" size="sm">Cancelar</Button>
<Button variant="accent" iconAfter="arrow-right" size="lg">Falar com a equipe</Button>
```

Variants: primary (navy), accent (controladas blue), secondary, ghost, danger, inverse (on navy). Sizes sm/md/lg = 32/40/48px. Never place two primaries side by side.
