# UI kit — Site institucional Opalus

Marketing/portal surface for the Grupo Opalus brand. Open `index.html`.

**Screens** (click the header nav to move between them)
- `HomePage.jsx` — navy hero with the node-mesh motif, the six-values pillar grid, open-indicators band, controladas cards, blue CTA band.
- `UnitsPage.jsx` — filterable unit list on `DataTable`, tabbed structure detail.
- `ContactPage.jsx` — contact panel + form on `Card`, submits to an inline success `Alert`.
- `Shared.jsx` — `Section`, `Eyebrow`, `SiteFooter`.

**Notes**
- No existing Opalus website was supplied with the brief. These screens are brand-faithful compositions built strictly from the Manual da Marca (colours, lockups, clear space, gradients) and the tokens in `/tokens` — they are *not* recreations of a live product.
- Photography is intentionally absent: no imagery was provided. Where a photo belongs (hero, unit cards) the abstract data illustrations stand in. Replace with real photography before production.
- All copy is placeholder Portuguese written in the brand's voice; the phone number, address and figures are invented.
